# 🌀 The Gravity Gauntlet (Гравитационная Хватка)

[![Minecraft](https://img.shields.io/badge/Minecraft-26.1-blue.svg?logo=minecraft)](https://www.minecraft.net/)
[![Fabric Loader](https://img.shields.io/badge/Fabric-0.20.1+-darkgreen.svg?logo=fabric)](https://fabricmc.net/)
[![Java](https://img.shields.io/badge/Java-25-orange.svg?logo=openjdk)](https://openjdk.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Полноценный физический манипулятор гравитационного поля нулевого уровня (**Zero-Point Energy Field Manipulator**) в стиле культовой гравипушки из **Half-Life 2**, созданный для **Minecraft 26.1** на **Fabric Loader**.

---

## ⚡ Ключевые возможности и механики

### 1. 🧲 Режим захвата и левитации (ПКМ / Правая кнопка мыши)
* **Дальность рейкаста**: 12 блоков.
* **Захват любых сущностей**: Мобы, животные, игроки, выброшенные предметы (`ItemEntity`), активированный динамит (`PrimedTnt`).
* **Вырывание блоков из мира**: Наведите прицел на любой твердый блок (камень, земля, доски, песок и т.д.) и нажмите ПКМ — блок с частицами разрушения извлекается из мира и переходит в левитирующий физический объект (`FallingBlockEntity`)!
* **Пружинная кинематика (Spring Damper System)**: Объект удерживается на дистанции 3.5 блоков перед игроком, плавно следует за прицелом на любой частоте кадров (60/144/240 FPS) без дёрганий и статтеров.
* **Гравитационный луч**: Потоки заряженных частиц (`ELECTRIC_SPARK`, `GLOW`) соединяют дуло пушки с захваченным объектом.
* **Безопасный сброс**: Повторный ПКМ аккуратно отпускает моба без урона или возвращает блок обратно в мир.

### 2. 💥 Сверхзвуковой кинетический выстрел (ЛКМ / Левая кнопка мыши)
* **Выстрел удерживаемым объектом**: Нажатие ЛКМ выстреливает моба, блок или динамит с сокрушительной скоростью **4.0** (артиллерийский снаряд)!
* **Звуковые и визуальные эффекты**: Тяжёлый акустический удар соника Вардена (`WARDEN_SONIC_BOOM`) и сокрушающий звук булавы (`MACE_SMASH`).
* **Кинетический урон и физика столкновений**: 
  * При ударе о препятствие или другого моба снаряд наносит сокрушительный урон (до 30+ HP) и мощный импульс отдачи по площади.
  * Блоки при ударе в стену эффектно раскалываются на осколки со звуком разрушения наковальни.
  * Запущенный динамит мгновенно детонирует при первом касании.
* **Репульсорная ударная волна (при пустом захвате)**: Конический залп энергии на 5.5 блоков вперед, раскидывающий всех врагов перед игроком с нанесением 7 ед. кинетического урона.

### 3. 🌀 Гравитационный вихрь предметов (Shift + ПКМ)
* Создает мощный магнитный импульс в радиусе **15 блоков**.
* Мгновенно притягивает к игроку все валяющиеся на земле предметы и сферы опыта.

### 4. 🎨 Двойная визуальная система (Minecraft Format 46+)
* **В инвентаре и хотбаре**: Четкая детализированная 2D пиксель-арт иконка 32x32.
* **В руках от 1-го и 3-го лица**: Полная объёмная 3D-модель (титановый корпус, рукоять, светящееся сингулярное ядро, 3 медные грави-катушки и когти-эмиттеры) с эргономичным прицеливанием.

## 🎮 Таблица управления

| Действие | Управление | Описание |
| :--- | :--- | :--- |
| **Захват / Отпустить** | `ПКМ` (Right-Click) | Захватывает моба/предмет или вырывает блок из мира. Повторный клик отпускает объект |
| **Кинетический выстрел** | `ЛКМ` (Left-Click) | Выстреливает захваченный объект со скоростью 4.0 или создает репульсорную волну |
| **Притяжение лута** | `Shift + ПКМ` | Притягивает все лежащие предметы и опыт в радиусе 15 блоков |

## 📦 Быстрая установка

1. Убедитесь, что у вас установлен **Minecraft 26.1** с **[Fabric Loader](https://fabricmc.net/)** (версии `0.20.1` или новее).
2. Скачайте готовый файл `gravitymod-1.0.0.jar` из папки [`release/`](release/gravitymod-1.0.0.jar) данного репозитория.
3. Поместите `.jar` файл в папку `.minecraft/mods/`.
4. Запустите игру и наслаждайтесь физикой!

---

## 🛠️ Сборка из исходников

### Требования:
* **JDK 25** (рекомендуется Eclipse Temurin или Microsoft OpenJDK 25)
* **Gradle 9.4+** (в репозиторий включен готовый `gradlew`)

### Инструкция по сборке:
```bash
# Клонируйте репозиторий
git clone https://github.com/ВАШ_НИКНЕЙМ/the-gravity-gauntlet.git
cd the-gravity-gauntlet

# Сборка проекта
./gradlew build
```
Готовый JAR-файл будет сгенерирован в каталоге `build/libs/gravitymod-1.0.0.jar`.
